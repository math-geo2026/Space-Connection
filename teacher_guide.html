🛰️ 공간잇기(空間+IT+Geo) — 교사 가이드

수업 전 준비 → 학생 화면 흐름 → 교사용 관제실(스프레드시트) → 실시간 웹 대시보드까지, 화면 캡처와 함께 따라가는 안내입니다. (인쇄하면 A4 6~7쪽 내외)
📱 태블릿(가로 모드) 사용을 권장합니다. 3D 도형을 손으로 돌리고, 점을 직접 찍는 활동이 많아 터치 조작이 가장 자연스럽습니다. PC(마우스)에서도 되지만 화면이 자동으로 확대되어 여백이 커 보일 수 있습니다.

0. 수업 전 준비 (한 번만)

준비 1

구글 스프레드시트 + Apps Script

  • 빈 스프레드시트를 만들고 확장 프로그램 → Apps Script에 reflectlog_apps_script.gs 내용을 붙여넣습니다.
  • 코드 위쪽 TEACHER_KEY = '0000'을 원하는 비밀번호로 바꿉니다. (교사용 관제실을 여는 비밀번호이자, 웹 대시보드 비밀번호로 공통으로 씁니다.)
  • 배포 → 새 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자) → 생성된 URL을 kosa.js의 KOSA.SHEET_URL에 넣습니다. (이미 넣어 둔 URL을 쓰는 경우 이 단계는 생략)
  • 코드를 고친 뒤에는 배포 관리 → 편집 → 새 버전으로 재배포해야 반영됩니다.
  • NEW스프레드시트를 처음 열면 🔒 표지(교사용 관제실) 시트가 자동으로 만들어지고 맨 앞에 뜹니다. 아래 "2. 교사용 관제실" 참고.
준비 2

배포 파일 올리기

  • GitHub Pages 등 정적 호스팅에 폴더째 업로드합니다. 필요한 파일: index.html hub.html perp_plane_class.html samsuseon.html jeongsayeong.html jeongsayeong_adv.html kosa.js three.min.js OrbitControls.js mars.jpg img_module1.jpg img_module2.jpg lambert_webtoon.png
  • 학생 접속 주소: https://math-geo2026.github.io/Space-Connection/
  • 연결 확인: 사령부(hub) 오른쪽 위 사용자 칩의 📡 시트 테스트를 누르면 시트 '접속기록' 탭에 (연결테스트) 행이 생깁니다. (원본 데이터 시트라 평소엔 숨겨져 있어요 — 아래 2단 잠금 참고)
파일을 새로 올린 뒤에는 태블릿에서 강력 새로고침(또는 브라우저 캐시 삭제) 후 접속하세요. 사령부에 접속하면 이후 모듈은 자동으로 새 버전을 받습니다.

1. 학생 화면 흐름 (3차시)

대문

대원 등록 → 브리핑

  • 학번(숫자 4~6자리)·이름을 입력하면 등록됩니다. 같은 기기에서 다시 들어오면 로그인이 유지되고, 진행 상태도 학번별로 이어집니다.
  • 브리핑은 신호 수신 콘솔: 다이얼을 돌려 주파수를 맞추면 화성 기지 영상이 선명해지고 교신이 타이핑됩니다. SKIP으로 건너뛸 수 있습니다.
  • 효과음(짧은 전자음)은 🔊 버튼으로 끌 수 있습니다.
  • NEW다이얼과, 교신이 끝난 뒤 나타나는 "임무 수락" 버튼에 손가락 아이콘이 한 번 반짝이며 다음 행동을 알려줍니다. (같은 학번으로 재접속하면 다시 안 뜸)
교신

수신 완료 → 임무 수락

  • 다이얼을 다 맞추면 기지 상태(구조 제어·안테나·패널·생명유지장치)가 자동으로 타이핑되어 나타나고, T−(붕괴까지) 카운트다운이 시작됩니다.
  • "✅ 임무 수락 → 사령부로" 버튼을 누르면 사령부(허브)로 이동합니다.
사령부

모듈 선택

  • 두 카드를 누르면 흑백 → 컬러로 살아나며 문제 상황이 타이핑되고 접속 버튼이 나타납니다.
  • 상단 상태판: 전력은 완수한 단계에 따라 23%→100%, T−(붕괴까지)는 72시간에서 완료한 차시마다 24시간씩 줄어듭니다.
  • 사용자 칩: 📡 시트 테스트 · 🧹 진행 초기화(이 학번의 기기 기록 삭제) · 로그아웃 · NEW🛰️ 교사용 관제소(웹 대시보드로 바로 이동).
  • NEW처음 들어온 학생에게는 1단계(MODULE 01) 카드에 손가락 아이콘이 한 번 반짝이며 "여기부터 시작하세요"를 알려줍니다.
1차시

MODULE 01-S1 직선과 평면의 수직

  • 교신(타이핑) → 🎯 복구 미션 → 슬라이더로 기둥 l을 레일 m, n과 직각으로 맞추기(정면·측면 시점 교차 확인).
  • 미션 완료 후 수학실험실이 열립니다: 정의·정리 → 작도(학생이 l 위를 터치해 P를 잡고 P′·선분을 그림) → 수직이등분선 → SSS/SAS 합동 빈칸 → 결론.
  • 실험실 뒤 요약 문항에서 "수직"을 고르면 설계 승인(칭찬 피드백 + 3D 직각 기호).
수학실험실

정의 → 작도 → 증명

  • 학생이 직접 직선 위를 터치해 점을 잡고, 대응하는 선분·수직이등분선을 그려보며 정리를 증명합니다.
  • NEW실험실을 마치고 관제소로 돌아오면, 이어서 봐야 할 "핵심 기하학 개념 최종 정리" 패널과 제출 버튼이 반짝이며 다음 행동을 안내합니다.
2차시

MODULE 01-S2 삼수선의 정리

  • 미션1·2·3이 각각 정리 ①②③에 대응합니다. 각 미션 완수 후 정리 카드에서 가정 조건 / 결론 버튼을 눌러 3D의 ⊥ 표시를 확인해야 다음으로 넘어갑니다.
  • 미션3 완수 → 🧩 문제탐구(회전 가능한 3D 원기둥 문항, 9단계) → 🧩 문제해결(수준별 3문항 중 1개는 수업, 나머지는 과제) → 📝 성찰로그.
  • 문제해결은 완수한 학번만 열리며, 집에서 같은 학번으로 접속해도 나머지 문제를 풀 수 있습니다.
  • NEW문제해결·추가문제 화면 하단에 ✏️ 풀이 쓰기 메모장이 있습니다. 접었다 펼 수 있고, Apple Pencil 필압도 인식하며 손가락으로도 쓸 수 있습니다(색상 3종·굵기 3단계·지우개·전체 지우기 지원). 추가문제는 문제 1·2·3마다 메모가 따로 저장되어 서로 안 섞입니다.
문제해결

3D 문항 + 단계별 STEP

  • 왼쪽엔 회전·확대 가능한 3D 도형, 오른쪽엔 STEP별 객관식으로 풀이 과정을 따라갑니다.
  • 기본/위에서/옆에서 시점 버튼으로 원하는 각도에서 관찰할 수 있습니다.
3차시

MODULE 02 정사영

  • 개념탐구: 패널을 기울이며 S′/S = cos θ 발견, 수선의 발 애니메이션(P를 따라가는 P′).
  • 개념이해: 정육면체·정사면체 속 정사영(기본 → 심화① → 심화②), 회전 관찰. 심화② 완료 시 "🚀 미션탐구로" 버튼.
미션탐구

그림자 최대의 순간

  • 교신(타이핑) → 그림자 최대의 순간 포착 → 왜 45°인지 카드로 식 만들기 → 그때의 그림자 넓이 → 성찰로그 → 추가문제(3D).
  • 읽을거리: Lambert 코사인 법칙 웹툰 + 직접 돌려보기.

2. 교사용 관제실 (스프레드시트) NEW

스프레드시트를 열면 🔒 표지 시트가 항상 맨 먼저 보입니다. 표지에는 여는 방법·시트 목차·데이터 흐름이 요약되어 있고, 잠금은 2단계로 나뉩니다.

0 표지만 보임 — 기본 상태. 다른 시트는 전부 숨겨져 있어 화면을 공유해도 학생 정보가 노출되지 않습니다.

1 🔓 교사용 보드 열기 (메뉴 → 비밀번호 입력) → 공간잇기_교사용 시트만 보임. 이탈자·학습부진자·우수자 요약이 최신 데이터로 자동 갱신되어 열립니다. 평소엔 이 단계까지만 여시면 충분합니다.

2 📂 학생 데이터(원본) 추가로 열기 (비밀번호 한 번 더) → 11개 단계별 로그, 모듈1·2 성찰로그, 접속기록, 실시간 — 원본 데이터 시트까지 전부 보임. 특정 학생 기록을 하나하나 들여다봐야 할 때만 여세요.

🔒 잠그기 — 두 단계 다 다시 숨기고 표지로 돌아갑니다. 수업 중 화면 공유 전에는 꼭 눌러주세요.

이 잠금은 "실수로 보이는 것"을 막는 용도입니다. 진짜 보안은 스프레드시트 자체의 [공유] 권한이니, 학생·외부인에게 편집/조회 권한이 없는지 꼭 확인하세요.
보드
